The Workout Tracker is a Python-based console application designed to help users log, track, and analyze their workout sessions. It allows you to record exercises, calculate training volume, monitor personal bests, and generate weekly summaries. All sessions are saved to a file (workouts.txt) so your progress is persistent across runs.

FEATURES
1.Log Workout Sessions  
2.Calculate Training Volume  
3.View All Sessions -Displays each session’s date and total training volume.
4.Personal Bests -Compares new exercise volumes against past sessions and highlights when you set a new personal best.
5.Weekly Summary  
6.Provides a summary of sessions completed in the current week, including:
-Total sessions
-Total training volume
-Most frequently trained exercise
-Average session volume
7.View Session by Date -Search for a specific session using its date (YYYY-MM-DD) and view all exercises logged that day.
8.Storage- All sessions are saved in workouts.txt and automatically loaded when the program starts.
